# 스도쿠 한 수 도우미

화면에서 클래식 스도쿠판을 가져와 숫자를 읽고, 논리적으로 확정할 수 있는 다음 한 수와 이유를 보여주는 작은 로컬 웹 앱입니다.

## 시작하기

화면 공유 기능은 보안상 로컬 주소에서 열어야 합니다. Python 3가 설치되어 있다면 스도쿠 도우미 시작.bat 파일을 더블클릭하세요. 브라우저가 자동으로 열립니다. 앱을 사용하는 동안 열린 검은색 창은 그대로 두세요. 사용을 마치면 그 창에서 아무 키나 눌러 서버를 종료할 수 있습니다.

직접 명령어로 실행하려면 프로젝트 폴더에서 아래 명령을 입력해도 됩니다.

    python -m http.server 8765 --bind 127.0.0.1

그 다음 브라우저에서 http://127.0.0.1:8765 를 여세요. 브라우저가 localhost를 사용하면 화면 공유 선택 창을 띄울 수 있습니다.

## 사용 방법

1. 화면 공유를 눌러 스도쿠 게임이 열린 화면이나 창을 선택합니다.
2. 게임 화면이 보일 때 현재 화면 캡처를 누릅니다.
3. 미리보기에서 스도쿠 격자만 드래그해 선택하고 숫자 읽기를 누릅니다. 이미지 파일을 열어 읽는 방법도 있습니다.
4. 인식한 숫자가 맞는지 확인하고, 틀린 칸은 스도쿠판을 눌러 수정합니다.
5. 오른쪽 풀이 설명을 확인한 뒤 이 숫자 입력하기를 눌러 다음 수를 반영합니다.

화면 공유와 OCR은 명시적으로 시작하거나 캡처했을 때만 진행됩니다. OCR은 브라우저 안에서 처리하며, 최초 사용 시 OCR 코드와 언어 구성 요소를 인터넷에서 내려받습니다.

## 현재 지원 범위와 다음 단계

- 화면이나 이미지에서 퍼즐판을 선택해 숫자를 인식합니다.
- 인식 결과를 9×9 입력판에서 바로 수정할 수 있습니다.
- 클래식 스도쿠의 단일 후보, 유일 후보, 박스-행/열 후보 제거, 2~3개 후보 묶음을 이용해 다음 확정 수를 찾습니다.
- 다음 단계에서는 규칙 정의에 대각선, 불규칙 영역, 킬러 케이지, 나이트 이동 제한 등의 제약을 추가할 수 있도록 풀이 엔진을 구성해 두었습니다.
