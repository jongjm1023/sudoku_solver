인식과 지원 규칙 안내

화면은 사용자가 선택하고 캡처한 뒤 이 브라우저 안에서 처리합니다. 숫자 인식 기능을 처음 쓸 때 OCR 구성 요소를 내려받으며, 화면 이미지 자체는 업로드되지 않습니다. 숫자를 잘못 읽은 경우에는 스도쿠판에서 직접 고쳐 주세요.

현재는 클래식 규칙에서 단일 후보, 유일 후보, 박스-행/열 후보 제거, 2~3개 후보 묶음을 이용해 다음 확정 수를 찾습니다. 2단계에서는 대각선, 킬러, 불규칙 영역 같은 규칙을 추가할 수 있도록 풀이 규칙을 별도 구성으로 관리합니다.

화면 공유는 브라우저의 허용이 필요합니다. 공유 중에도 캡처는 버튼을 눌렀을 때만 진행돼요.
